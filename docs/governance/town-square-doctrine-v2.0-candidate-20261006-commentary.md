### Traceability and non-goals

The prior draft remains historical input; no rule ID is silently reused as an active authority. The companion profiles supply exact field names, object vocabulary, receipt shape, and lifecycle transitions so the founding text remains portable. The candidate intentionally does not require hidden reasoning, any cloud, any file service, or a particular wake product.
